openapi-conformance
===================

OpenAPI conformance tables to ensure my cdd-* are fully compliant.

Basically you can give an LLM https://raw.githubusercontent.com/OAI/OpenAPI-Specification/refs/heads/main/versions/3.2.0.md but it's not in the best format for LLMs to confirm compliance.

Markdown is an ok format, probably XML would be better; but this works.
